# Notification System

This repository contains the solution for the frontend evaluation.

## Project Structure

- `notification_app_fe`: React frontend built with Vite.
- `notification_app_be`: Node.js Express backend.
- `logging_middleware`: Custom logging middleware used by the backend.
- `notification_system_design.md`: Architecture and design documentation.

## Setup Instructions

### Backend
1. Navigate to `notification_app_be`.
2. Run `npm install`.
3. Start the server with `node server.js`.

### Frontend
1. Navigate to `notification_app_fe`.
2. Run `npm install`.
3. Start the development server with `npm run dev`.

## Features
- Real-time notifications (Planned)
- Dashboard for monitoring system status (Planned)
- Integrated logging for all backend requests.
